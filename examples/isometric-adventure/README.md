# The Sunstone Relay

A title and three playable scenes lead to a complete isometric quest.

1. Press **START** on the title. Talk to **Keeper Nia** with **A** in Keeper Village.
2. Take the east exit to **Windridge**. Step on the west and east gold beacons. The shrine opens after both are lit.
3. Enter **Sunstone Sanctum**, claim the lake core with **A**, then speak to Nia to restore dawn.
4. Advance the ending with **A**, then press **START** to return to the title and reset the quest.

On the diamond grid, Up moves north-east, Down south-west, Left north-west and Right south-east. Hold a direction to walk, or tap it for one cell. The browser uses arrows, **X** for A and **Enter** for START.

Returning between areas preserves progress. Repeating a beacon or collecting an object twice cannot increase the objective count. START only advances the title or the finished ending.

The example and portable template share the same scenes, scripts and assets. Campaign tests check collision reachability, supported events, objective gates, return visits, completion and replay. GitHub Actions builds both ROMs for the browser player.

Art combines local pixel art with redistributed CC0 sources. See `third_party/showcase-art/README.md` in the repository for credits and licenses. No commercial ROM assets are bundled.
